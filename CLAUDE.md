## Устройство проекта

- `src/index.html` — **страница целиком** (шапка документа, стили, разметка, скрипт, разметка для поисковиков, Метрика). Все правки только здесь.
- `src/facade.jpg` — обложка (солнечная, сгенерирована по реальному фото; вывески перенесены с оригинала); `src/facade-real.jpg` — настоящее фото, запасной вариант; `src/facade-depth.jpg` — карта глубины обложки (Depth Anything V2); `src/depth.jpg` — она же с впечённой границей неба, её берёт сайт (`img/depth.jpg`).
- `src/rooms/<номер>-<N>.jpg` — фото номеров (до 1800 px); список — `PHOTOS` в скрипте. `src/static/` — значки, картинка для соцсетей и шрифты (`fonts/`: Lora, Golos Text, Geologica — кириллица, латиница, расширенная латиница для ₽; лицензия OFL), копируются как есть. Шрифты подключены в `<head>` (`@font-face`), к Google страница не обращается (Inter с Google тянет только модуль HomeReserve). `src/privacy.txt` — текст политики обработки персональных данных.
- `python tools/build.py` — сборка в `site/`: страница (без разделов с заглушками в [скобках], скрипт сжат), обложка и фото номеров в webp (1800/760/160), `privacypolicy/`, `404.html`, `robots.txt`, `sitemap.xml`, `.htaccess`. Папка `site/` в git не хранится.
- Проверки (поднимают `site/` локальным сервером `tools/serve.js`, нужен Playwright с Chromium: `npm i playwright`, `npx playwright install chromium`):
  - `node tools/qa.js` — вёрстка на 15 ширинах; после `ISSUES` и `ERRORS` должно быть пусто;
  - `node tools/site-check.js` — сайт целиком (ошибки, битые картинки, просмотр фото, политика, служебные файлы); с адресом — проверка живого сайта: `node tools/site-check.js https://preview.hotellegenda.ru`;

  - `node tools/serve.js` — сайт в браузере на http://127.0.0.1:8765.
- Панель «Погода» (переключатель погод для проверки) видна на `preview.*`, локально и по `?demo`, на рабочем домене спрятана (`hidden`).

- **Решения владельца по погоде:**
  - время суток (солнце, луна, звёзды, облака) поверх фото **убрано**, код удалён (ноябрь 2026); время суток осталось только в цвете плашки «Сейчас в Терсколе» в меню и полосы под «чёлкой» телефона (`--sky1`, `--sky2`);
  - текстовые подсказки под погоду («на склонах свежий пухляк» и т. п.) **убраны** — не возвращать;
  - пасмурно, туман — **фото без эффектов** (туман и облака поверх солнечного фото выглядели как плёнка);
  - осадки — частицы плюс лёгкое приглушение фото (CSS-фильтр по `data-wx` на `#hero`, массив `VEIL`); метель — тонкая белая мгла; гроза — заметно темнее, с молниями;
  - плашка «Сейчас в Терсколе» в меню логотипа меняет цвет по погоде (владельцу нравится); строки «Ресторан открыт» в меню нет;
  - **высоту снега не показывать** (ноябрь 2026): Open-Meteo даёт модельную оценку по ячейке сетки со склонами — при дожде в Терсколе показывала «снега 8 см».

Если меняется фото обложки — пересчитать карту глубины (`src/facade-depth.jpg`), затем `python tools/sky-mask.py` (впекает точную границу неба по цвету фото и пишет `src/depth.jpg`; без этого ясное небо даёт кайму на крыше).
  - **Точки на фото** — объект `PHOTO` в координатах исходника 2000×1333: труба `chimney`, потолок крыльца `porch`. При смене фото — пересчитать.
  - **Дым из трубы** (всегда), сносится реальным ветром.
  - **Тёплый свет** в дождь, мокрый снег, сильный снег, метель, грозу (канвас `#fxWin`, рисуется один раз, плавно появляется прозрачностью): только крыльцо, освещённое лампой под потолком. **Свет в окнах (больших и подвальных) и светящуюся гирлянду владелец отверг** — не возвращать, пока нет способа сделать по-настоящему реалистично.
  - **Ясное небо**: в ясно (80%) и переменную облачность (40%) небо на фото (по маске неба) мягко тонируется в глубокий голубой — канвас `#fxSky`, строится один раз, проявляется за 3 с. Не мультяшно: только цвет, без анимаций.
  - **Молния**: разряд сбоку по небу, вспышка освещает фасад, зарница — только в небе.
