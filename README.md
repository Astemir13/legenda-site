# Сайт эко-отеля «Легенда»

Статичный сайт отеля в Терсколе: фотографии номеров, отдельные схемы планировок, подбор по вместимости и реальное бронирование HomeReserve.

## Исходники и запуск

- `src/legenda-template.html` — контент, базовые стили и поведение.
- `src/redesign.css` — актуальное оформление, включается сборкой в оба HTML-файла.
- `index.html` — предпросмотр с оптимизированными локальными изображениями.
- `dist/legenda-tilda.html` — HTML для блока T123; стили страницы ограничены `#lg`.
- `tools/build.py` — сборка без сторонних Python-пакетов.
- `src/room-photo-sources.json` — источники фотографий категорий.
- `src/room-retouched-v2/` — шесть обработанных фото 1448×1086 и промпт.
- `src/facade-winter-v1.webp`, `src/facade-summer-v1.webp` — сезонные изображения.

```sh
python tools/build.py
python -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Сборка ничего не публикует. Не редактировать сгенерированные HTML вручную.

## Оформление и фото

Inter Variable, зелёные основные кнопки, умеренные скругления, компактная форма. В общей полосе первого экрана расстояния, погода, рейтинг, парковка и питомцы. Фото номеров показываются сразу; схемы открываются кнопкой «Планировка».

Ретушь и летняя версия созданы встроенным imagegen. Активные изображения хранятся в WebP. Генеративная обработка может менять мелкие детали. Промпты: `src/facade-retouched-v1.prompt.txt`, `src/facade-retouched-v2.prompt.txt`, `src/facade-summer-v1.prompt.txt`, `src/room-retouched-v2/prompts.txt`. Предыдущие PNG и варианты остаются локальным архивом и исключены из Git.

Сезоны сменяются растворением за 3 секунды каждые 11 секунд без контролов: между переходами 8 секунд неподвижного кадра. Первый переход через 11 секунд после загрузки летнего изображения. При `prefers-reduced-motion` остаётся зимний кадр; в скрытой вкладке таймер приостанавливается.

## Данные и бронирование

Настройки находятся в `BOOK`, `HR`, `REST`, `LAT`, `LON`, `ELEV`, `DIST`, `rooms`, `PLANS` исходника.

Интеграция HomeReserve и ID объектов сохранены из `origin/main` (`ae2e231`). Поисковая форма сервиса монтируется скрыто, видимая форма сайта остаётся компактной. Форма сайта проверяет вместимость и считает ориентировочную сумму. Фактические цены, наличие и оплата находятся в HomeReserve. Даты и взрослые передаются в модуль параметрами `begin_date`, `end_date`, `adults` вместе с ID категории. Возраста детей отдельно пока не собираются. При недоступности внешнего скрипта открывается обычная ссылка сервиса; в резервном сценарии даты нужно выбрать повторно.

Площади сверены с каталогом HomeReserve 29.10.2026: стандарт 24 м², трёхместный 32 м², полулюкс 35 м², семейный 32 м², люкс 37 м², барнхаус 80 м². Планировки схематичны.

Отзывы — короткие выдержки из [Яндекс Карт](https://yandex.ru/maps/org/legenda/1184772629/reviews/), статичный снимок: 5,0; 1292 оценки, 687 отзывов, на 29.10.2026. Автоматического обновления нет.

Погода запрашивается у Open-Meteo по координатам отеля каждые 15 минут. При ошибке меню и карточка показывают отсутствие данных без выдуманной температуры. Во время проверки запрос завершался таймаутом; реальные данные в этом окружении не подтверждены. Демо-инструменты доступны с `?weather=demo` и подписаны.

## Экспорт для Тильды

`python tools/build.py [URL_фасада]` собирает блок T123. Экспорт использует существующие официальные CDN-ссылки фотографий. Ретушь и летний кадр пока относятся к `index.html`: для Тильды их нужно разместить на разрешённом хостинге и настроить URL. Ни сборка, ни PR не обновляют Тильду.

Содержимое `dist/legenda-tilda.html` вставляется целиком в T123. Глобальное оформление HomeReserve оставлено отдельно, поскольку сервис монтирует своё окно вне `#lg`. Встраивание в настоящую страницу Тильды не проверялось.
