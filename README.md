# Сайт эко-отеля «Легенда»

Сайт [hotellegenda.ru](https://hotellegenda.ru): живая погода в Терсколе на фото обложки, подбор номера, фото и схемы номеров, дорога до отеля. Новая версия до запуска — [preview.hotellegenda.ru](https://preview.hotellegenda.ru).

## Что где лежит

| Путь | Что это |
|---|---|
| `src/index.html` | **Страница целиком.** Все правки делаются здесь |
| `src/rooms/` | Фото номеров (`std2-1.jpg` …); список — `PHOTOS` в скрипте страницы |
| `src/facade.jpg`, `src/depth.jpg` | Фото обложки и карта глубины к нему (для погодных эффектов) |
| `src/static/` | Значки сайта, картинка для соцсетей, шрифты (`fonts/`) |
| `src/privacy.txt` | Текст политики обработки персональных данных |
| `tools/build.py` | Сборка: `python tools/build.py` → папка `site/` |
| `tools/site-zip.py` | Архивы `site/` для загрузки через файловый менеджер Timeweb |
| `tools/qa.js`, `tools/site-check.js`, `tools/weather-shots.js` | Проверки и снимки (Playwright) |
| `docs/SEO.md` | Продвижение, хостинг Timeweb, порядок запуска |
| `CLAUDE.md` | Правила проекта и памятка для Claude Code |

## Как обновить сайт

1. Правка в `src/index.html` (или фото в `src/rooms/`).
2. `python tools/build.py` — собрать `site/`.
3. `node tools/qa.js` и `node tools/site-check.js` — проверить.
4. `python tools/site-zip.py site-zip` — архивы для загрузки.
5. Timeweb → файловый менеджер → `tilda/public_html` → «Загрузить» каждый архив → «Распаковать».

## Частые правки

Всё, что меняется чаще всего, собрано в начале скрипта в блоке **«НАСТРОЙКИ САЙТА»** (в `src/index.html`):

- `BOOK` — ссылка на онлайн-бронирование;
- `REST` — часы ресторана;
- `LAT`, `LON`, `ELEV` — координаты и высота отеля для погоды;
- `DIST` — расстояния до Чегета и Азау;
- `rooms` — номера: цены, описания, метки;
- `PLANS` — схемы планировок.

Правило: меняйте только текст в кавычках и числа; кавычки, запятые и скобки не трогайте.
