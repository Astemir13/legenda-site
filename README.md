# Сайт эко-отеля «Легенда»

Новая главная страница [hotellegenda.ru](https://hotellegenda.ru): живое небо по реальной погоде в Терсколе, подбор номера, схемы планировок, дорога до отеля.

## Что где лежит

| Путь | Что это |
|---|---|
| `dist/tilda-blok-1.html` | **Блок 1 для Тильды:** стили и разметка. Вставляется в первый блок T123 |
| `dist/tilda-blok-2.html` | **Блок 2 для Тильды:** скрипт. Вставляется во второй блок T123, сразу под первым |
| `index.html` | Предпросмотр с панелью «Погода»: можно переключать погоду и время суток |
| `src/legenda-template.html` | Исходник. Все правки делаются здесь, потом сборка |
| `src/facade.jpg` | Фото фасада для предпросмотра |
| `tools/build.py` | Сборка: из исходника делает два файла для Тильды (`dist/tilda-blok-*.html`) и `index.html` |
| `logo/logo-legenda.svg` | Горы из логотипа в векторе |

## Как обновить сайт на Тильде

Тильда не сохраняет в одном блоке T123 больше ~120 000 знаков, поэтому код разделён на два блока, которые стоят друг под другом: сначала блок 1, под ним блок 2.

1. Открыть `dist/tilda-blok-1.html` → кнопка **Raw** → выделить всё → скопировать.
2. В Тильде: верхний блок T123 → «Контент» → выделить всё → вставить → «Сохранить и закрыть».
3. То же для `dist/tilda-blok-2.html` и нижнего блока T123.
4. «Опубликовать». Если правка была только в тексте/стилях — часто достаточно обновить один блок, но надёжнее обновлять оба.
5. Проверка: первая строка каждого блока начинается с `<!-- Эко-отель «Легенда» · главная · блок N из 2`, блок 2 заканчивается на `</script>`.

## Частые правки

Всё, что меняется чаще всего, собрано в начале скрипта в блоке **«НАСТРОЙКИ САЙТА»** (в `src/legenda-template.html`):

- `BOOK` — ссылка на онлайн-бронирование;
- `REST` — часы ресторана;
- `LAT`, `LON`, `ELEV` — координаты и высота отеля для погоды;
- `DIST` — расстояния до Чегета и Азау;
- `rooms` — номера: цены, описания, метки;
- `PLANS` — схемы планировок;
- `LINES` — фразы под погоду.

Правило: меняйте только текст в кавычках и числа; кавычки, запятые и скобки не трогайте.

## Сборка

```
python3 tools/build.py https://static.tildacdn.com/…/facade.jpg
```

Аргумент — ссылка на фото фасада в Тильде. Без неё в файле останется метка `ССЫЛКА_НА_ФОТО_ФАСАДА`.

## Предпросмотр на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту предпросмотр откроется по адресу `https://<ваш-логин>.github.io/legenda-site/` — там погода уже настоящая. Страница закрыта от поисковиков, чтобы не спорить с основным сайтом.
